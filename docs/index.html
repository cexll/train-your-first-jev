Start from a question that has a right answer, then work through the data, the training, the calibration, and the reload. Every lesson comes with an exercise you can try right away.

Study the lessons online, run the training locally.
This page gives you interactive exercises and real experiment logs; it does not train Qwen in the browser. The actual LoRA training runs through the terminal course in the repository and needs no paid model API. That terminal course is written in Chinese.

This is an independent teaching project for a Jev-style choice model. It is not the official TypeSafe Jev and does not reproduce its private RLCD method.
